桌面端 AI 编码智能体应用 OurCode 的主界面（1440×900 桌面视口），方案 C「极简对话优先」，参考 Claude Desktop / ChatGPT 桌面端的极简架构：无常驻文件树、无常驻面板，居中窄对话列 + 行内产物卡片，IDE 能力收进右下角悬浮抽屉。浅色玻璃拟态风格：应用背景 #f6f7fb，白色圆角卡片（圆角 16px，hairline 描边 rgba(15,23,42,0.08)，极浅投影），主色 #0058bc 仅用于主按钮/选中态/进行中；文字 #0f172a / #334155 / #64748b；成功 #16a34a、警告 #d97706、错误 #dc2626；代码块 #0f1420；用户气泡 #e8f0ff；字体 Plus Jakarta Sans，代码 JetBrains Mono；正文 14px 行高宽松；所有 UI 文案为简体中文。整体大量留白、安静克制。

布局结构：
1. 极简顶栏（高 52px，无边框仅留白）：左侧仅 OurCode 小 logo + 当前会话标题「修复 Composer 抖动」；右侧仅三个图标按钮：历史、共享、设置。
2. 左缘会话抽屉（收起态，宽 56px 的纯图标竖条）：logo、新建对话 +、搜索、任务、历史、设置五个图标，当前对话图标高亮蓝色。
3. 居中对话列（720px 定宽，大量留白）：用户消息浅蓝气泡 #e8f0ff 圆角 16px；AI 回复无气泡纯文本排版，两段分析文字；内嵌一张深色代码卡片（#0f1420，圆角 12px，标签栏 ChatInput.tsx · TypeScript，含行号与语法高亮，右上「复制」）；下方一行浅色文件 chip：「📎 ChatInput.tsx +24 −6」「📎 useAutoResizeTextarea.ts +11 −2」可点击；再下方折叠条「▸ 查看执行轨迹 · 18 步 · 40s」；底部一条浅蓝 #e8f0ff 内嵌提示条「● 正在运行 pnpm test:unit… · 停止」。
4. 右下角悬浮「工作区」按钮：白色圆角胶囊带蓝色图标与「工作区 2」字样，暗示可展开 Diff/终端抽屉；旁边一个向上的小圆钮「回到最新 ↑」。
5. 底部居中输入胶囊（720px 与对话列同宽，圆角 16px，白色玻璃卡带轻投影）：占位「给 OurCode 发消息，或 @ 引用文件…」，下方一行小控件：左「📎 附件」「⚙ 自动执行 ▾」「Claude 3.7 Sonnet ▾」，右蓝色圆形发送按钮；胶囊下缘小字「OurCode 可能出错，请核对重要改动 · Enter 发送 / Shift+Enter 换行」。
