桌面端 AI 编码智能体应用 OurCode 的主界面（1440×900 桌面视口），方案 E「检查点时间线」：参考 Replit Agent 与 Cursor Checkpoints —— 以垂直执行时间线为主画布，每个关键动作都是一个可回退的检查点，右侧常驻实时预览。浅色玻璃拟态风格：应用背景 #f6f7fb，面板为白色圆角卡片（圆角 16px、面板间 8px 间隙、hairline 描边 rgba(15,23,42,0.08)、极浅投影），主色 #0058bc 仅用于主按钮、当前检查点、进行中状态；文字 #0f172a / #334155 / #64748b；状态色 成功 #16a34a、警告 #d97706、错误 #dc2626；代码块/终端/预览窗背景 #0f1420（界面唯一深色块）；用户消息气泡 #e8f0ff；字体 Plus Jakarta Sans，代码/路径用 JetBrains Mono；正文 13-14px；面板标题 12px 大写字母加宽字距；90% 中性色，无大面积渐变。所有 UI 文案为简体中文。

2. 左侧任务栏（232px）：顶部「+ 新任务」蓝色主按钮；下方任务列表按「运行中 / 排队 / 已完成」分组，每项标题 + 迷你进度条，如「重构对话主画布 3/5」「补 OAuth2 回归测试 2/4」「周报数据看板 排队中」。
3. 中央检查点时间线（约 620px 定宽）：垂直轨道 + 节点卡片，从上到下：
   - 「任务创建 14:02」小节点
   - 「检查点 01 · 理解需求」卡：内嵌计划摘要 3 行 + 「查看完整计划」链接
   - 「检查点 02 · 读取 12 个文件」卡：文件 chip 流（Canvas.tsx、layout.css、App.tsx 等，等宽字体）

   - 「检查点 04 · 单测通过 24/24」卡（绿色对勾徽标）
   - 末尾进行中节点「正在运行 Playwright 冒烟测试…」+ 加载动画
   每张卡右上角灰色小字时间戳，卡片悬停态出现「⏪ 从此回退」幽灵按钮。
