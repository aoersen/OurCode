已深度排查 ChatInput.tsx 与 useAutoResizeTextarea.ts 的渲染生命周期。

问题根源在于：流式文字逐步推入时，ResizeObserver 捕获高度变化的微任务执行时机，与浏览器原生文本流引发的滚动位置补偿发生了并发竞争，导致 DOM 重排瞬间产生 10px 的垂直位移抖动。

为保证完全不触及外部主轴 Flex 树结构，方案锁定在输入框内部运用 GPU 硬件加速的 transform: translateY(...) 与动态 contain: paint 做局部边界隔离。以下为核心修复补丁：
